This directory includes a few matlab files for different modeling exercises, including fitting RDMC to congruency effects and CSEs of each conflict task. 

The descriptions below briefly explain the purposes of each m file (i.e., functions) or mat file (i.e., data that matlab can read)

"spatialStroop_SOA_ReadData.mat" -- Empirical spatialStroop data organized in terms of congruency level
 
"flanker_SOA_ReadData.mat" -- Empirical flanker data organized in terms of congruency level 

"spatialStroop_CE_SOA" -- a function for computing the g-squared value for the spatialStroop task regarding congruency level 

"wrapper_spatialStroop_CE_SOA" -- a wrapper function for preparing the simplex search

"spatialStroop_CE_SOA_SIMPLEX" -- a function that performs the simplex search for the spatialStroop task

"flanker_CE_SOA" -- a function for computing the g-squared value for the flanker task regarding congruency level 

"wrapper_flanker_CE_SOA" -- a wrapper function for preparing the simplex search

"flanker_CE_SOA_SIMPLEX" -- a function that performs the simplex search for the flanker task

"chisquare_difference" -- The function for estimating the goodness-of-fit for each task concerning congruency level and congruency sequence

"spatialStroop_CE_SOA_fit" -- plot CDFs, delta plots, and CAFs of the best-performing model for the spatialStroop task regarding congruency level

"flanker_CE_SOA_fit" -- plot CDFs, delta plots, and CAFs of the best-performing model for the flanker task regarding congruency level

"spatialStroop_SOA_CSE_ReadData.mat" -- Empirical spatialStroop data organized in terms of congruency sequence

"flanker_SOA_CSE_ReadData.mat" -- Empirical flanker data organized in terms of congruency sequence

"spatialStroop_CSE_SOA" -- a function for computing the g-squared value for the spatialStroop task regarding congruency sequence 

"wrapper_spatialStroop_CSE_SOA" -- a wrapper function for preparing the simplex search regarding congruency sequence 

"spatialStroop_CSE_SOA_SIMPLEX" -- a function that performs the simplex search for the spatialStroop task regarding congruency sequence 

"flanker_CSE_SOA" -- a function for computing the g-squared value for the flanker task regarding congruency sequence 
 
"wrapper_flanker_CSE_SOA" -- a wrapper function for preparing the simplex search regarding congruency sequence 

"flanker_CSE_SOA_SIMPLEX" -- a function that performs the simplex search for the flanker task regarding congruency sequence 

"spatialStroop_CSE_SOA_fit" -- plot CDFs, delta plots, and CAFs of the best-performing model for the spatialStroop task regarding congruency sequence

"flanker_CSE_SOA_fit" -- plot CDFs, delta plots, and CAFs of the best-performing model for the flanker task regarding congruency sequence
